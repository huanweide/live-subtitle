## 它解决什么问题

想在电脑上看外语影片、直播、网课，但听不懂，也不想等字幕组。

市面上有两条路，但都差点意思：

- **网页插件**（沉浸式翻译之类）——只认 YouTube / Netflix 那种标准播放器，遇到自建播放器的站点就抓不到字幕
- **系统实时字幕**——Windows 自带的实时字幕**没有日语语音包**（官方只提供中文、英文、法文、德文、意大利文、韩文、葡萄牙文、西班牙文、丹麦文）

这个工具走第三条路：**直接把系统正在播放的声音"接"出来**，所以你不论用什么播放器、什么网站，它都能翻。

而且识别这一步是在**你自己的显卡上**跑的，声音不会上传到任何地方。

## 翻译用的是谁

识别在你自己电脑上跑，**翻译这一步要调一个大模型接口**，所以得有个 API 密钥。

默认用[**硅基流动**](https://cloud.siliconflow.cn/i/axOmWfWi)。挑它的理由：

- **中文译得好**——它自家的 Qwen 系列本来就是中文模型，日译中比拿英文模型硬转顺得多
- **注册就送额度**——够你把这个工具试透
- **按量便宜**——一小时的影片译下来通常几分钱
- **接口通用**——兼容 OpenAI 格式，哪天想换别家，配置里改两行就行

从[这个链接](https://cloud.siliconflow.cn/i/axOmWfWi)注册（邀请码 `axOmWfWi`），
你那边是正常的新用户赠送额度，我这边会多一张 16 元的券——算是对这个开源项目的一点支持。

不感兴趣也完全没问题：**双击字幕条打开设置窗口，里面有个「翻译接口」**，
可以直接换成 OpenAI、本地 Ollama，或者填自己的接口地址和密钥变量名。

> **密钥不会写进配置文件**——配置文件里只存「从哪个环境变量取密钥」。
> 这样即使配置文件被人看到、或者误传到仓库，密钥也不会泄露。

## 安装

### 第 1 步：把文件弄到本地

```powershell
git clone https://github.com/huanweide/live-subtitle.git
cd live-subtitle
```

没有 Git 就点右上角 **Code → Download ZIP**，解压到任意文件夹。

### 第 2 步：跑安装脚本

在那个文件夹里开 PowerShell，敲：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

它会自己做七件事：

1. 看看你电脑的底子（PowerShell 版本、是不是 64 位、硬盘还剩多少）
2. 看显卡，决定给你装 GPU 版还是 CPU 版
3. 下载 whisper.cpp 主程序（有 N 卡 643 MB，没有 8 MB）并解压
4. 下载识别模型（默认 1.5 GB，可以换小的）——**国内连不上 HuggingFace 会自动换 hf-mirror 镜像**
5. 列出你电脑上所有**正在工作**的录音设备
6. 放一段英文试听，看选的编号有没有声音进来（试不出来也不影响，回头在设置里换）
7. 写好配置文件

装完双击 `启动字幕.bat` 就能用。

> **先跑 `setup.ps1`，再双击 `启动字幕.bat`。**
> 顺序反了也不会闷声失败：程序发现引擎或模型不在，会**弹一个窗口**告诉你差什么、该做什么。
>
> **第一次启动要等 5～10 秒**——它在把模型读进显卡，之后每次都是秒开。
>
> 有 N 卡的话，**全新装的第一次**可能更久（一两分钟）：显卡要现场编译 CUDA 内核。
> 编译一次就存下来了，往后不再等。这段别以为卡死了。

**它不会动你原有的设置**：已经配好的字号、位置、识别语言都会保留，只补该补的。

## 手动安装

自动脚本跑不通的话，按下面手动来。

**① 找「立体声混音」**

右键任务栏的小喇叭 → 声音设置 → 更多声音设置 → **录制** 选项卡。
如果看不到「立体声混音」，在空白处右键 → 勾选「显示禁用的设备」，再右键它 → **启用**。

**② 下 whisper.cpp**

去 [whisper.cpp releases](https://github.com/ggml-org/whisper.cpp/releases)，找一个**带安装包的版本**（最新那个只有版本号的是空的，往下翻一个），下载：

- 有 N 卡：`whisper-cublas-12.4.0-bin-x64.zip`
- 没 N 卡：`whisper-bin-x64.zip`

解压到 `whispercpp-gpu\`（有 N 卡）或 `whispercpp\`（没 N 卡）目录下。

**③ 下模型**

从 [whisper.cpp 模型列表](https://huggingface.co/ggerganov/whisper.cpp/tree/main) 下载 `ggml-large-v3-turbo.bin`，
放进 `models\` 目录。

> 这个模型是多语言的，日语、英语、韩语……都认。
> 国内下不动可以换镜像：把 `huggingface.co` 换成 `hf-mirror.com`

**④ 填密钥**

复制 `subtitle-config.example.json` 成 `subtitle-config.json`，照着里面的说明填翻译接口的密钥。

**⑤ 启动**

双击 `启动字幕.bat`。

## 用法

**启动**：双击桌面上的 **「实时字幕」** 图标。程序在后台运行，**不会出现黑色命令行窗口**，
右下角托盘区会出现一个小图标，屏幕右下角（默认位置）出现字幕条。

| 你做什么 | 会怎样 |
|---|---|
| **鼠标移到字幕条上** | 右下角一排按钮变亮（平时半透明、**一直看得见**，不用记任何手势） |
| **点 `+` / `−`** | 整条放大 / 缩小（宽、高、字号一起变），自动保存 |
| **点 `◐`** | 切换透明度：`0.95 → 0.80 → 0.62 → 0.45 → 0.30`。**只有背景变透明，文字始终不透明** |
| **点 `✕`** | 隐藏字幕条（托盘菜单「显示 / 隐藏字幕条」可以叫回来） |
| **点 `⚙`** | 打开完整设置窗口（语音 / 外观 / 翻译 / 高级 四组） |
| **拖 `◢`（最右）** | 自由缩放整条，松手自动记住 |
| **按住字幕条任意处拖动** | 挪位置，松手自动记住；**整条会被夹在屏幕内**，不会拖出去找不回来 |
| **右键字幕条** | 快捷菜单 |
| **左键点托盘小图标** | 暂停 / 继续字幕 —— 图标在**绿点**（在跑）和**灰点**（暂停）之间切换 |
| **右键托盘小图标** | 🚀 快速设置（三步）· ⚙ 打开设置… · 显示 / 隐藏字幕条 · 暂停字幕 · 环境自检… · 退出 |
| **在字幕条上滚轮** | （快捷方式）整条缩放 |
| **按 `Ctrl+Alt+Z`** | 切换「字幕条挡不挡鼠标」（可在 **设置 → 高级** 里关掉） |

### 三步快速设置（第一次用就点这个）

右键托盘小图标 → **「🚀 快速设置（三步）」**：

```
第 1 步 · 听什么声音       → 选录音设备（一般选「立体声混音」）
第 2 步 · 要不要边听边翻译 → 打勾 / 取消（取消就只显示识别出的原文，不联网）
第 3 步 · 翻译成哪种语言   → 默认简体中文，也可选英语 / 日语 / 韩语 / 俄语 / 法语 / 德语 / 西班牙语
```

窗里有 **「打开完整设置」**——识别语言（日语 / 英语…）、字号、颜色那些进阶项在那里。

> **为什么看不到黑窗口了**：以前用 `.bat` 启动，Windows 一定会给它开一个控制台窗口；
> 现在改用 `启动字幕（无窗口）.vbs`，用「窗口样式 0」拉起 PowerShell，控制台窗口从头到尾不创建。
> 想在终端里看日志调试时，仍然可以右键 `启动字幕.bat` 运行（那个会显示窗口）。

**三种状态怎么看**：

| 字幕条显示 | 意思 |
|---|---|
| 灰字 `● 实时字幕已启动 · 在等声音…` | 正在听，但没听到人说话 |
| 白字中文 + 浅蓝原文 | 正在翻译 |
| 停 10 秒后回到灰字 | 上一句已经过期了 |

## 常见问题

**Q：字幕一直不出来 / 不知道哪儿出的问题？**

**右键托盘那个小图标 → 「环境自检…」**，它会列一张清单，逐项告诉你：

```
[OK]  配置文件      D:\...\subtitle-config.json
[OK]  识别引擎      D:\...\whispercpp-gpu\Release\whisper-stream.exe
[OK]  识别模型      D:\...\models\ggml-large-v3-turbo.bin
[!!]  录音设备      有 3 个，但没有「立体声混音」
        这台机器的声卡驱动可能不提供它；用耳机听的话，可以选名字带「耳机」的那个试试
[OK]  翻译密钥      环境变量 SILICONFLOW_API_KEY 里找到了
[OK]  显卡加速      检测到 N 卡，走 GPU 路线
```

**哪项标 `[!!]`，就看它下面那行提示。**同一份报告也会存成 `自检报告.txt`，方便贴给别人看。

（从「双击黑条 → 设置窗口 → **环境自检**」也能打开。）

**Q：字幕条全黑，一个字都没有？**
那是**没听到人说话**，不是在报错。除非你正在放的片段确实有人说话却不出字，那才是问题。

**Q：不出字怎么办？**
1. 先确认影片**确实在响**（不是静音、不是耳机没插好）
2. 打开 `debug.log` 看最后几行
3. 双击黑条打开设置，把「**录音设备**」换一个编号再试——这一项最常出问题

**Q：录音设备该选哪个？**
看你在哪听声音：

- **用耳机听** → 选名字里带「耳机」的那个，或者「立体声混音」
- **外放听** → 选「立体声混音（Stereo Mix）」
- 选错了后果是：字幕条一直停在灰字，因为它录到的是一段静音

编号列表里第一个（`0 · 麦克风阵列`）通常录的是**你的说话声**，不是电脑放的声音。

**Q：换成了英语，字幕还是不出？**
先把影片暂停、再播放——识别进程换语言时要重开一次。
还不行就打开设置窗口，确认「识别语言」那一栏确实是「英语」。

**Q：字幕条挡住了播放器的按钮？**
按 `Ctrl+Alt+Z`，或者右键 → 「鼠标点不到字幕条」。

**Q：为什么偶尔会冒出「感谢您的观看」？**
这是 Whisper 对**静音**的幻觉——它听过太多影片片尾，一遇到安静就想写这句。
项目内置了 28 条黑名单（日语 16 条、英语 9 条、中文 3 条）自动挡掉。如果还有漏网的，欢迎提 Issue。

**Q：声音会不会被传到网上？**
**不会。** 声音全程在你电脑里，从不外传。
只有**识别出来的那行原文文字**会发到翻译接口。如果你要连文字都不外传，
可以换成离线翻译模型（见「开发计划」）。

## 原理

```
影片的声音
   ↓ whisper-stream.exe 抓录音设备（在显卡上跑）
原文文字
   ↓ 写进 ws-live.txt
   ↓ 主脚本每 0.8 秒读一次
   ↓ 符合改写规则的黑名单词直接丢掉
中文译文
   ↓ 画在一条置顶的无边框窗口上
```

**为什么用「文件」当中转**：`whisper-stream.exe` 是独立程序，跟主脚本没法直接通话。
让它把结果写进 txt，主脚本守着读——土办法，但稳定。

**为什么把设备编号、模型路径、语言都放进配置文件**：这些东西每台电脑都不一样，
写死在脚本里就没法给别人用了。现在 `setup.ps1` 探一遍、写进 json，脚本只负责读。

**为什么不自己做语音识别**：Whisper 是 OpenAI 开源的，质量是目前最好的之一，
没必要重复造轮子。

## 文件都是干什么的

| 文件 | 干什么的 |
|---|---|
| `实时字幕.ps1` | 主程序：字幕条窗口、托盘菜单、设置界面、翻译 |
| `setup.ps1` | 一键安装：找显卡、下引擎、下模型、探设备、写配置 |
| `启动字幕（无窗口）.vbs` | **推荐入口**：双击后后台运行，不出现黑窗口（桌面快捷方式指向它） |
| `实时字幕.ico` | 程序图标（桌面快捷方式用） |
| `启动字幕.bat` | 老入口：会在终端里跑（好处是能直接看到输出，调试用） |
| `subtitle-config.json` | 你的设置（不进 Git） |
| `subtitle-config.example.json` | 设置模板，给手动安装的人看 |
| `ws-live.txt` | 识别引擎的原始输出，主脚本读它 |
| `debug.log` | 出问题看这个 |
